# portfolio สาขา Artificial Intelligence and System (วิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ) วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยสงขลานครินทร์ วิทยาเขตภูเก็ต| สิมิลันนา พาล์เมียรี่ ชไวเกิร์ต

เว็บไซต์พอร์ตโฟลิโอสำหรับสมัครฝึกงานและสหกิจศึกษาในตำแหน่ง AI และ ML Engineer พัฒนาขึ้นเพื่อแสดงผลงานโปรเจกต์ด้านปัญญาประดิษฐ์ ระบบประมวลผลภาษาธรรมชาติ คอมพิวเตอร์วิทัศน์ และใบประกาศนียบัตรวิชาชีพ

## เทคโนโลยีและฟีเจอร์หลัก
- เฟรมเวิร์ก: Next.js (App Router), React, TypeScript
- การจัดหน้า: Tailwind CSS และ UI แบบกระจกใส
- โปรเจกต์ AI และ Machine Learning ที่น่าสนใจ:
  - ChatLert: ระบบจัดการข้อความแชทภาษาไทย (Thai NLP) 8 ขั้นตอน พร้อมเว็บแอปพลิเคชัน Streamlit
  - Smart Tomato Disease Classification: ระบบจำแนกโรคใบมะเขือเทศด้วย Deep Learning ใช้ PyTorch และ EfficientNet-B3
  - CoC QA Dashboard: เว็บแดชบอร์ดวิเคราะห์ข้อมูลบทความวิชาการ
- ฟีเจอร์โต้ตอบ: หน้าต่างทดลองใช้งานโปรเจกต์ ระบบสไลด์ดูรูปใบประกาศนียบัตรหลายใบ และหน้าดูเรซูเม่ในตัว
